<h2 id="reading-map">Read the map</h2>

Start with your application code, then follow the connections to the data or
background work it needs. Arrowheads show **who initiates the labeled call or operation**, not which
way all the data travels. A Worker can read from or write to storage through
the same binding; responses return to the caller. Solid lines show calls,
while dashed lines show message publishing, delivery, or Workflow creation. This is an example of how the products
can fit together, not a stack that requires every product.

Hover or focus an icon for a field note. **Click a product to explore its own
architecture, local-development options, usage limits, and sources.**
